# Emotion Detection From Text

## Project Overview
Emotion Detection From Text is a Python-based Machine Learning project that identifies emotions expressed in text messages.

The project uses a pre-trained DistilBERT emotion classification model to analyze text and predict the associated emotion.

## Features
- Accepts text messages from users.
- Detects emotions from text.
- Uses a pre-trained Transformer model.
- Supports interaction through a Telegram bot.

## Technologies Used
- Python
- Hugging Face Transformers
- PyTorch
- python-telegram-bot

## Project Structure
- `emotion_detection.py` – Main Python source code
- `requirements.txt` – Required Python libraries
- `.gitignore` – Files excluded from Git tracking

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/karishmashaik-186/Emotion-Detection-From-Text.git
   ```

2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

3. Configure your Telegram bot token securely as an environment variable before running the application.

4. Run the Python file:
   ```bash
   python emotion_detection.py
   ```
